# 내가 찾은 부산 영화촬영지

초등학생이 부산의 실제 촬영 사례를 조사하고, 자신이 고른 부산의 장소를 새 영화촬영지로 추천하는 수업용 웹앱입니다. 로그인, Firebase, API 키가 필요 없는 정적 웹앱입니다.

## 학생 활동

1. **촬영지 탐험**: 흰여울문화마을–변호인, 국제시장–국제시장, 광안리·광안대교–블랙 팬서, 아홉산숲–군도의 사례를 살펴봅니다. 실제 촬영 사실, 사진 관찰, 새 장면 상상을 구분합니다.
2. **사진 관찰**: 사진에서 발견한 모습을 기록하고, 그 모습이 영화 배경에 어떤 도움이 될지 생각합니다.
3. **추천서 만들기**: 실제 촬영지 4곳, 부산시민공원, 다대포해수욕장 또는 직접 찾은 장소를 고릅니다. 이름·위치, 특징, 새로운 장면, 추천 이유, 촬영 약속을 한 질문씩 작성합니다. 학교나 동네 장소도 자유롭게 입력할 수 있습니다.
4. **발표·저장**: 1485 × 2100픽셀 PNG 추천서를 저장합니다. 이름·별명 및 1~6모둠은 선택 사항입니다. 발표 질문과 크게 보기 기능이 있습니다.

추천 장소의 사진은 선택 사항입니다. 직접 찍은 JPG·PNG·WebP(15MB 이하)를 넣거나, 손가락·펜으로 새 장면을 그리거나, 사진 없이 완성할 수 있습니다. 사진은 기기 안에서 축소·처리됩니다.

## 화면과 수업

- 기본 본문 22px, 높이가 낮은 태블릿에서는 21px입니다. 태블릿 가로 화면에 맞춰 주요 활동과 이전·다음 버튼을 한 화면에 배치했습니다.
- 작은 화면·세로 화면·화면 키보드가 열리는 경우에는 필요한 만큼 스크롤할 수 있습니다. 화면 확대·접근성 글꼴 설정에 따라서도 스크롤이 생길 수 있습니다.
- 사진 ‘크게 보기’, 수업 도움, 낱말, 출처도 페이지를 넘겨 볼 수 있습니다.
- 40분 수업 예시: 촬영지 탐험 10분 → 관찰 기록 5분 → 추천서 20분 → 발표 5분.
- 소개한 영화를 감상하지 않아도 활동할 수 있습니다. 영화 장면이나 예고편을 삽입하지 않았습니다. 사진은 실제 장소의 관광·기록 사진입니다.

## 기록과 제출

- 글·사진·그림은 이 기기·이 브라우저의 localStorage에 자동 저장됩니다. 새로고침 후 이어 쓸 수 있습니다.
- 장소를 바꾸면 각 추천 장소의 작성 내용이 따로 보관됩니다.
- ‘도움 · 자료 → 기록’에서 JSON 백업·불러오기를 할 수 있습니다. 불러오기와 기록 삭제는 확인 화면을 거칩니다.
- 브라우저 데이터 삭제·시크릿 창 종료 시 기록이 사라질 수 있습니다. 결과 PNG나 JSON을 저장하세요. 저장 공간이 부족하면 백업 안내가 표시됩니다.
- 자동 제출·학급 실시간 동기화는 없습니다. 저장한 PNG를 선생님의 패들렛·학급 제출함 등에 올립니다.

## GitHub + Vercel 배포

제공 ZIP에서는 앱 파일이 압축의 맨 위에 있습니다.

1. ZIP을 풉니다. `index.html`, `app.js`, `data.js`, `style.css`, `assets` 폴더를 확인합니다.
2. 새 GitHub 저장소를 만들고 **Add file → Upload files**로 파일과 `assets` 폴더 전체를 올립니다. ZIP 자체를 올리지 않습니다.
3. Vercel에서 **Add New → Project → Import Git Repository**로 저장소를 선택합니다.
4. Framework Preset **Other**, Root Directory **index.html이 있는 폴더**(맨 위에 올렸다면 `.`)를 선택합니다.
5. Build Command·Install Command는 비워 두고, Output Directory는 기본값 또는 `.`으로 배포합니다.
6. 배포된 HTTPS 주소를 학생에게 공유합니다. 환경 변수·API 키가 필요 없습니다.

개발용 소스 저장소에서는 앱이 `dist/`에 있습니다. 이 저장소 자체를 Vercel에 연결한다면 Output Directory를 `dist`로 지정하세요. 빌드 명령은 필요 없습니다. 제공 ZIP은 `dist` 없이 바로 배포할 수 있도록 구성했습니다.

## 자료 수정

- `data.js`: 실제 촬영 사례·사진 메타데이터·낱말·도움말
- `app.js`: 단계별 활동, 자동 저장, 사진·그림, PNG 내보내기
- `style.css`: 큰 글씨, 태블릿·모바일 레이아웃
- `assets/`: 실제 장소 사진, Jua 글꼴과 사용 허가문
- `SOURCES.md`: 촬영 사실·사진별 원문·저작자·사용 조건

외부 JavaScript·CDN·지도 API를 사용하지 않습니다. 원문 링크를 누를 때 외부 사이트로 이동합니다. 서비스 워커를 사용하지 않으며 완전한 오프라인 설치 앱은 아닙니다.

## 검증

1024×768 및 1024×680 태블릿 가로 화면에서 주요 활동과 이전·다음 버튼 배치를 확인했습니다. 1024×680에서 실제 촬영지 4곳의 4개 주제와 추천서 7개 질문 화면에 가로 넘침·활동 패널 잘림이 없음을 확인했습니다. 1280×800과 모바일 390px 화면도 확인했습니다. 직접 입력한 장소로 관찰 → 추천 → 그림 첨부 → PNG 저장을 진행했고, 사진 첨부·새로고침 후 이어 쓰기·JSON 백업과 불러오기를 확인했습니다. PNG는 최대 입력 글자 수에서도 한 장 안에 표시되는지 확인했습니다.
